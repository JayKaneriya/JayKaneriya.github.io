# Website V5 — Final QA & Launch Checklist

## Positioning
- Senior Full-Stack Laravel/PHP Developer is the primary identity.
- Vue.js, React and React Native are supporting technologies.
- Paperly is the first professional case study.
- Availability is stated as available now.

## SEO / sharing
- Keep one clear title per page.
- Keep a useful meta description on the homepage and case-study pages.
- Keep canonical URLs consistent with the public GitHub Pages URL.
- Keep Open Graph/Twitter metadata aligned with the page title and description.
- Keep structured data factual; do not add invented ratings, clients or metrics.

## Links
- Prefer HTTPS for all external project links.
- Verify every portfolio link before launch.
- Do not expose private client credentials, API keys or secrets in the repository.

## GitHub Pages
- GitHub Pages supports HTTPS on github.io sites automatically.
- If a custom domain is added later, verify the domain first and enable Enforce HTTPS.
- GitHub recommends verifying a custom domain to reduce takeover risk.

## Mobile / accessibility
- Check the homepage and every case-study page at phone, tablet and desktop widths.
- Check keyboard focus, visible link states, image alt text and heading hierarchy.
- Avoid text embedded only in images for important information.

## Conversion
- Primary CTA: View Work
- Secondary CTA: Hire Me / Contact
- Keep LinkedIn and GitHub links easy to find.
- Make availability visible without making the site feel like a job-board profile.

## Do not change without evidence
- Client/company names
- User counts
- Revenue
- Performance percentages
- Project ownership claims
- Employment dates
- Testimonials
