Problem

Megathy was a multi-vendor on-demand grocery delivery platform for Eastern Saudi Arabia. The product needed catalogues across sellers, flexible delivery scheduling, cash and card payments, real-time order tracking, discounts/loyalty and customer support across web and mobile.

Contribution

  • Built the Laravel backend, admin panel and order management used for day-to-day operations.
  • Shipped a multi-vendor product catalogue with order management and scheduled delivery slots.
  • Implemented real-time tracking, cash/card payments, discounts, loyalty and live chat support.
  • Delivered mobile/web experiences with React Native, Vue.js/jQuery, MySQL, Sass, Bootstrap and Firebase for supporting mobile features.

Technical implementation

  • Backend / admin: Laravel, MySQL, JSON APIs, Git
  • Frontend: Vue.js, JavaScript, jQuery, AJAX, Bootstrap
  • Mobile: React Native, Firebase
  • Domain features: multi-vendor catalogue, scheduled slots, payments, loyalty, live support

Outcome

The project demonstrates end-to-end delivery across backend, admin tooling and mobile: catalogues, ordering, scheduled slots, live tracking, payments, support and loyalty — without inventing unverified metrics.
