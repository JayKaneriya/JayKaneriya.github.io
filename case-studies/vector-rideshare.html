Problem

Vector Rideshare is a university carpooling application connecting students, parents and faculty through a .edu-verified network. Users need to create trips, find rides to a destination, schedule travel and communicate with trip creators.

Contribution

  • Built the mobile experience in React Native for both iOS and Android from one codebase.
  • Integrated Firebase and REST APIs for auth, trip data and realtime messaging.
  • Implemented trip creation/joining, destination search, scheduled trips and realtime chat.
  • Restricted the network to .edu-verified university users for trust and safety.

Technical implementation

  • Stack: React Native, Firebase, REST APIs, JavaScript ES6, Git, JSON, NPM
  • Product surface: .edu community, trip create/join, search, scheduling, realtime chat

Outcome

The project demonstrates production mobile delivery across iOS and Android with Firebase/REST integration, realtime chat, scheduling and an identity-gated university community model.
