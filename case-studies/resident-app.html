Resident App — housing community workflows

Personal project · Laravel · Vue.js · MySQL · REST API

NoticesSociety updates in one feed
RequestsMaintenance / complaint tracking
MembersProfiles for residents & admins

01 Context

Residential societies still run on WhatsApp groups and paper registers. Residents need a simple place for notices, complaints, and everyday community tasks.

02 Responsibility

Personal product ownership — domain modeling, Laravel APIs, Vue interfaces and admin workflows for housing communities.

03 Challenges

  • Replacing chat chaos with structured notices and request tracking.
  • Clear roles for residents and society admins.
  • Keeping the product simple enough for non-technical users.

04 Solution

  • Resident-facing flows for notices and maintenance requests.
  • Admin tools for assignment and status updates.
  • Laravel + Vue stack for fast iteration and clean API boundaries.

05 Outcomes

A personal product that shows real-world domain modeling — roles, requests, and community communication — useful for proptech and local SaaS conversations.

06 Technology

  • Stack: Laravel, Vue.js, MySQL, REST API
  • Focus: notices, maintenance requests, member profiles, admin workflows
