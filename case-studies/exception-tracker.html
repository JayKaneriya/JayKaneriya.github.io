Exception Tracker — production error triage

Personal project · Laravel · Vue.js · MySQL · REST API

GroupSimilar exceptions collapsed for faster triage
SeverityCritical / warning levels for priority work
SearchHistory you can query when incidents hit

Problem

Production exceptions scatter across logs. Without grouping and a clear dashboard, developers waste time hunting the same bug twice.

Approach

  • Built a Laravel API to ingest and store exception events.
  • Vue dashboard for browsing, filtering, and severity-based prioritization.
  • Searchable history so recurring issues are visible across deploys.

Outcome

A personal full-stack monitoring tool that demonstrates production thinking — not just CRUD demos. Useful as a reference for SaaS ops and developer tooling work.
